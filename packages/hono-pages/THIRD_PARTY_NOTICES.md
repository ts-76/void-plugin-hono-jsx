## Void, @void/react and @void/md

Source distributions: `void@0.26.0` and `@void/react@0.26.0`, published npm packages. Link, prefetch lifecycle and form API behavior also reference the published `@void/react@0.27.0` adapter. Hono's render/navigation integration uses the public `void@0.26.1` / `void@0.27.0` navigation engine and router facade, with lifecycle behavior adapted from Void's router. Markdown script extraction, component-tag splitting and entry conventions reference the published `@void/md@0.27.0` implementation; its MIT attribution is preserved here. Markdown parsing uses the public `markdown-exit` and `yaml` APIs as optional peers. No private `@void/md` module is imported. The adapter imports framework APIs rather than bundling the framework.
